🧩 Módulos avançados

Cadastre dados estruturados em JSON. Os dados ficam salvos no servidor e são enviados em tempo real aos overlays conectados. Os controles de visibilidade preservam os dados quando desligados.

Exemplo de jogador: {"number":10,"name":"Nome do jogador","position":"Atacante","captain":false}. Para escalações, use lineups.home e lineups.away; cada uma pode conter coach, starters e bench.

📺 Instalação no OBS Studio

  1. Deixe este programa aberto no computador.
  2. No OBS, clique em Fontes → + → Navegador.
  3. Nomeie a fonte como Placar LLTV BRASIL.
  4. URL:
  5. Defina largura 1920 e altura 1080.
  6. Confirme. O fundo do overlay é transparente.

O overlay é uma página web local; não é um plugin nativo instalado dentro do OBS. Para OBS em outros computadores, configure hospedagem HTTPS ou Cloudflare Tunnel; este ZIP não cria sozinho um endereço público.

📱 Acesso pelo celular

Conecte o celular à mesma rede Wi‑Fi do computador e abra o endereço de rede exibido na janela do servidor, com /panel.html?token=.... Se o Windows perguntar, permita o acesso na rede privada. Não compartilhe o link com pessoas não autorizadas.

Se não abrir, verifique a rede Wi‑Fi e o Firewall do Windows. O painel deve permanecer em execução no computador.
