O projeto não cria automaticamente um domínio público. Para acesso fora da rede, configure um endereço público HTTPS por meio de hospedagem ou proxy seguro. Não exponha a porta diretamente sem proteção.

Instalação no Android

Quando o site estiver publicado por HTTPS, abra-o no Chrome e escolha Instalar aplicativo ou Adicionar à tela inicial. Na rede local HTTP, a instalação PWA pode não aparecer; use o navegador normalmente.

Este pacote inclui a versão web instalável (PWA), não um APK Android compilado. Nenhum link de APK é inventado ou apresentado como se estivesse hospedado.
