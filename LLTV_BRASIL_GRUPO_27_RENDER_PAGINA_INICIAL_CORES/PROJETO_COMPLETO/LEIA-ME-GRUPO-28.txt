LLTV BRASIL PLACAR PRO — GRUPO 28
PLACAR PRINCIPAL + MINI PLACAR + CONTROLE DE TRANSMISSÃO

BASE: Grupo 27 (projeto completo)

ALTERAÇÕES:
1. Removidas as faixas pretas de fundo do placar principal; as áreas do mandante e visitante ocupam a altura total com as cores cadastradas.
2. Placar principal apresenta os nomes completos dos clubes.
3. Mini Placar apresenta as siglas cadastradas, sem escudos.
4. Controle de transmissão ganhou a opção “Mini placar (siglas)”. Ao ativar, substitui o principal; ao desativar, retorna ao principal.
5. Os dois modelos usam os mesmos gols, cronômetro, período, acréscimos e rodada, atualizados pelo mesmo estado da partida.
6. Preservados os módulos e arquivos anteriores do Grupo 27.

INSTALAÇÃO:
- Extraia o ZIP.
- Envie o conteúdo da pasta PROJETO_COMPLETO para a raiz do repositório GitHub, mantendo as pastas.
- No Render, mantenha Build Command: npm install e Start Command: npm start.
- Faça deploy e atualize o overlay no OBS com Ctrl+F5 ou recarregando a fonte Browser.

TESTES EXECUTADOS:
- node --check public/app.js
- node --check public/overlay.js
- node --check server.js
- Integridade do arquivo ZIP.

LIMITAÇÃO:
Não foi realizado teste visual no OBS nem deploy real na conta Render. A validação acima é de sintaxe JavaScript e integridade do pacote.
