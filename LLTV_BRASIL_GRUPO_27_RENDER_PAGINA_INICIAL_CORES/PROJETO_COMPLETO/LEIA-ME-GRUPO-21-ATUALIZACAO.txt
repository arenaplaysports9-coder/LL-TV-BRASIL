GRUPO 21 — ATUALIZAÇÃO: EQUIPE DE ARBITRAGEM E NARRAÇÃO

Este pacote atualiza o Grupo 21 anterior e mantém os controles individuais do overlay.

NOVO NO PAINEL
- Aba Ocorrências: formulário Equipe de arbitragem e narração.
- Arbitragem: árbitro principal, assistente 1, assistente 2, quarto árbitro e VAR.
- Transmissão: narrador, comentarista, repórter e apresentador.
- Botão para salvar os dados da equipe.

NOVO NO OVERLAY OBS
- Cartão de arbitragem independente.
- Cartão de narração/transmissão independente.
- Campos sem preenchimento não são exibidos.
- Controles individuais em Controles gerais > Controles de exibição do placar.
- Os dados são sincronizados em tempo real pelo Socket.IO e salvos junto ao estado da partida.

INSTALAÇÃO
1. Faça backup do projeto atual.
2. Extraia este ZIP.
3. Substitua a pasta do projeto no GitHub mantendo a estrutura de diretórios.
4. Aguarde o deploy no Render.
5. No painel, abra a aba Ocorrências para cadastrar os profissionais.
6. Em Controles gerais, ative/desative separadamente Equipe de arbitragem e Equipe de narração e transmissão.

Não foram alterados os dados existentes do placar. Se houver um arquivo data/match.json, o servidor incorpora os novos campos sem remover os demais dados.
