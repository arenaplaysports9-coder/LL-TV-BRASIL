GRUPO 22 — CONTROLES MOSTRAR / OCULTAR

Esta atualização parte do pacote do Grupo 21 e acrescenta controles separados MOSTRAR e OCULTAR para cada elemento listado em Controles de exibição do placar.

ARBITRAGEM
A equipe de arbitragem é tratada como um único bloco: os profissionais continuam cadastrados nos campos próprios, mas MOSTRAR ARBITRAGEM / OCULTAR ARBITRAGEM controla o bloco inteiro.

NARRAÇÃO E TRANSMISSÃO
Os campos e o funcionamento de cadastro existentes foram preservados. Foram acrescentados os botões MOSTRAR NARRAÇÃO / OCULTAR NARRAÇÃO para controlar o bloco da equipe no overlay.

DEMAIS ELEMENTOS
Cada item da lista de controles do overlay apresenta dois botões: MOSTRAR e OCULTAR. Mostrar ativa a chave do elemento; Ocultar desativa. Nenhum dos botões apaga dados. A sincronização continua usando Socket.IO e o estado de recursos existente.

INSTALAÇÃO
1. Faça backup do projeto atual.
2. Extraia o ZIP mantendo a pasta LLTV_Brasil_Placar_Pro.
3. Copie/substitua os arquivos mantendo a estrutura do repositório.
4. Envie para o GitHub e aguarde o deploy no Render.
5. Atualize a página do painel e a fonte Navegador do OBS, se necessário.

Arquivos alterados: public/app.js, public/index.html, public/style.css.
